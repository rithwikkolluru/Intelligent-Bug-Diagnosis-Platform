# Tech Stack

| Component | Choice | Alternatives considered | Reason |
| --- | --- | --- | --- |
| Backend API | FastAPI | Flask, Django | Fast, typed, easy API validation |
| Database | SQLite + SQLAlchemy | PostgreSQL | Simple local-first foundation |
| Validation | Pydantic v2 | Marshmallow | Strong schema validation and Python typing |
| Frontend | React + Vite | Next.js, plain HTML | Lightweight SPA for fast iteration |
| Styling | Plain CSS | Bootstrap, Tailwind | Keeps dependencies minimal |
| Testing | pytest | unittest | Widely used and easy to extend |
| Linting | ruff | flake8 | Fast and modern Python linting |
| Package manager | pip + npm | Poetry, yarn | Simple and explicit |
